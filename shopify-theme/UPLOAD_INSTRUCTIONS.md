# How to upload this theme to Shopify

## Step 1 — Zip the theme
Select all files/folders inside `shopify-theme/` and compress them into a `.zip` file.
The zip must contain: assets/, config/, layout/, locales/, sections/, templates/
(Do NOT zip the shopify-theme folder itself — zip its contents.)

## Step 2 — Upload to Shopify
1. Go to your Shopify admin → Online Store → Themes
2. Click "Add theme" → "Upload zip file"
3. Select your zip file → click Upload

## Step 3 — Upload your logo
1. In the theme editor → Header section → upload your logo image

## Step 4 — Upload the hero video
1. In Shopify admin → Content → Files → upload your MP4 video
2. In the theme editor → Hero section → select the video from Files
   (Until you have a real video, the hero shows a dark gradient placeholder)

## Step 5 — Set up navigation
1. Go to Online Store → Navigation → "Main menu"
2. Add links. For the landing page sections use:
   - Home → /
   - About → /#about
   - Layers → /#layers
   - Contact → /#contact

## What's editable in the Theme Editor
Every section can be customized without code:
- **Header**: logo, navigation menu, CTA button
- **Hero**: video, eyebrow text, heading, subtitle, button
- **About**: heading, body text, button, stats (add/remove/reorder)
- **Layers/Pods**: heading, pod cards (add/remove/reorder each card, colors, features)
- **Waitlist**: all text, success message, footer text

## Adding new pages
Online Store → Pages → Add page
The page will use the default page template (clean content area).
